# Hostel Mess Foot-Traffic Optimization & Food Waste Reduction Analytics

A full-stack web application designed for Hostel Mess management, featuring live foot-traffic optimization, food waste tracking, menu polls, feedback management, and user check-ins.

## 📁 Repository Structure

```
.
├── backend/       # Node.js + Express REST API backend
│   ├── data/      # JSON database files
│   └── src/       # Express routes, controllers, and models
├── frontend/      # React + Vite frontend application
│   ├── public/    # Static assets
│   └── src/       # Components, pages, styles, and utilities
└── README.md
```

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation & Setup

1. **Backend Setup**:
   ```bash
   cd backend
   npm install
   npm run dev
   ```
   The backend server runs on `http://localhost:5000`.

2. **Frontend Setup**:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
   The frontend development server runs on `http://localhost:5173`.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, Lucide Icons, Recharts, CSS3 (Glassmorphism design)
- **Backend**: Node.js, Express.js, File-based JSON data stores
